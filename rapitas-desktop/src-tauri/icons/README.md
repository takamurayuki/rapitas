# アイコンの生成

Tauriのビルドには以下のアイコンファイルが必要です：

- `32x32.png` - 32x32ピクセル
- `128x128.png` - 128x128ピクセル
- `128x128@2x.png` - 256x256ピクセル (Retina用)
- `icon.icns` - macOS用
- `icon.ico` - Windows用

## 自動生成方法

1. 1024x1024以上の正方形PNG画像を用意
2. Tauri CLIでアイコンを生成:

```bash
cd rapitas-desktop
npx tauri icon path/to/your/icon.png
```

これにより、すべての必要なサイズが自動生成されます。

## マスターと図形の構成

| マスター | 用途 |
| --- | --- |
| `app-icon.svg` | アプリアイコンの 64px 以上（`*.png`、`icon.ico` の 64/128/256 フレーム、`icon.icns` の全フレーム） |
| `scripts/render-small-icons.py` | 16〜48px の小サイズ（`icon.ico` の 16/20/24/32/48 フレーム、`32x32.png`、トレイ用 `tray-icon-{16,20,24,32}.png`）。傾けた図形をそのまま縮小すると縁がにじむため、同じ傾きの図形を行を少し太くし、縁が最もくっきりする位置にずらして描き直している。64px 以上は `app-icon.svg` のまま |

図形はスマホ版アイコン（`rapitas-mobile/ios/Runner/Assets.xcassets/AppIcon.appiconset/Icon-App-1024x1024@1x.png`）と同じ構成です。
スマホ版は全面塗りで、デスクトップ版はそこに角丸タイル（`rx=213`）をかけただけです。図形を縮小しないでください。タイルの内側はスマホ版と 1px 単位で一致します。

システムトレイは `tray-atlas.png` から必要なフレームを切り出します。16〜64px の全整数サイズを個別描画しており、175% の28px、300% の48pxにも拡大縮小なしで対応します。Windows ではタスクバーの DPI と small-icon メトリクスからサイズを取得し、2秒ごとに変更を確認します。シェルが取得できない場合と他 OS ではメインモニターの倍率にフォールバックします。64px を超えるサイズは64pxに制限します。

トレイ図形は元の −10° の傾きと帯の長さ順を維持し、16px 基準で帯の厚み2px・行の中心間隔4pxとしています。各行の先頭には2pxの独立した四角を置き、線との間隔を1.5px確保しています。傾斜の縁にはアンチエイリアスが残ります。`tray-icon-{16,20,24,32}.png` は比較用に同じ描画から出力します。

トレイだけの再生成: `python rapitas-desktop/scripts/render-small-icons.py --tray-only`。通常実行はアプリ用の小サイズも生成するので、トレイ調整ではこのオプションを使ってください。
