# 配信ログ（TestFlight）

rapitas-mobile の iOS ビルドを TestFlight に配信した記録。CI が通ったことと、
実際に配信されて端末に入ったことは別の証跡なので、後者をここに残す。

## 運用ルール

- develop へのマージで Xcode Cloud のビルドが走ったら、App Store Connect で
  ビルドの成否を確認し、**確認できたものだけ**表に 1 行追記する（新しい行を下に足す）。
- 失敗したビルドも 1 行残す（結果欄に「失敗」と理由の要約）。
- 確認していない項目は推測で埋めず、「未確認」と書く。ビルド番号・日付は
  App Store Connect の表示どおりに転記する。
- 端末での確認は、実機にインストールして起動できたことを確かめた場合に記入する。
