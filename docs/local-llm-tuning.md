# ローカルLLM（Ollama）チューニングガイド

普通のPC（GPUなし / RAM 8〜16GB を想定）で、ローカルLLMの**能力**と**速度**を最大限に引き上げるための設定手順です。

rapitas は「キャッシュ → ローカルLLM(Ollama) → Haiku → Sonnet」の順でコストを最適化してルーティングします。ローカル段を強くするほど、無料・低コストで処理できる範囲が広がります。

---

## 1. モデルを格上げする（能力の主役）

既定のローカルモデルは超小型の **Qwen2.5-0.5B** で、能力が限られます。普通のPCなら **3Bクラス**が能力と速度の最適バランスです。

```bash
# 能力の主役（3B・推奨）。どちらか一方でOK
ollama pull qwen2.5:3b-instruct
# または
ollama pull llama3.2:3b

# 些末なルーティング用に小型も入れておくと速い（任意）
ollama pull llama3.2:1b

# RAM 16GB 以上なら 7B も実用的（さらに高能力）
ollama pull qwen2.5:7b-instruct
```

> アプリは**インストール済みの中から最も能力の高いモデルを自動選択**します
> （`services/local-llm/local-model-selector.ts`）。上位モデルを `pull` するだけで
> 品質が上がり、コード変更は不要です。

---

## 2. GPUを使う（速度の主役）

Ollama は **GPUを自動利用**します（NVIDIA CUDA / AMD ROCm / Apple Metal / Intel・新しめのGPUは Vulkan）。GPUがあれば数倍速くなります。

- GPUがある場合: 何もしなくてOK（Ollama が自動でオフロード）。
- GPUがない場合: CPUで動作。下記のチューニングと 1〜3B モデルで実用速度を狙います。

> アプリ同梱の `llama-server` フォールバックは **CPU専用**です。可能な限り
> **Ollama を起動しておく**（`ollama serve` / 常駐）ことを推奨します。

---

## 3. Ollama の環境変数で高速化・省メモリ

OS の環境変数として設定します（Windows はシステム環境変数、再起動後に有効）。

| 環境変数                  | 推奨値  | 効果                                               |
| ------------------------- | ------- | -------------------------------------------------- |
| `OLLAMA_KEEP_ALIVE`       | `30m`   | モデルを常駐させ、毎回の再ロード遅延（数秒）を排除 |
| `OLLAMA_FLASH_ATTENTION`  | `1`     | Flash Attention で高速化・省メモリ                 |
| `OLLAMA_KV_CACHE_TYPE`    | `q8_0`  | KVキャッシュを量子化しメモリ約半減（長文で効く）   |
| `OLLAMA_NUM_PARALLEL`     | `1`     | 普通PCは同時実行1で安定（アプリ側も直列化済み）    |

> アプリのローカル呼び出しは Ollama ネイティブ API 経由で `keep_alive=30m` と
> `num_ctx=4096` を**自動付与**します（`utils/ai-client/ollama-provider.ts`）。
> 上の `OLLAMA_KEEP_ALIVE` はサーバ全体の既定値で、二重の保険になります。

---

## 4. 量子化（メモリと品質のトレードオフ）

- 既定の **Q4_K_M** はサイズ・速度・品質のバランスが良く、まずはこれで十分。
- RAM に余裕があれば **Q5_K_M / Q6_K** で品質を底上げできます（`ollama pull qwen2.5:3b-instruct-q5_k_m` など、提供タグに依存）。

---

## 5. 目安（CPUのみ・量子化Q4_K_M）

| モデル        | 必要RAM(目安) | 体感速度        | 用途                         |
| ------------- | ------------- | --------------- | ---------------------------- |
| 0.5B          | ~1GB          | 非常に速い      | ルーティング等の最小限       |
| 1B            | ~1.5GB        | 速い            | 軽い分類・短い整形           |
| **3B（推奨）**| ~3GB          | 実用的          | enrich・要約・着想など主用途 |
| 7B            | ~5〜6GB       | やや遅い(CPU)   | より高品質（RAM16GB+）       |

---

## 6. 反映確認

1. 上記モデルを `pull` し、Ollama を起動（`ollama serve` または常駐アプリ）。
2. rapitas を再起動（バックエンドのローカルモデル選択が更新されます）。
3. インストール済みモデル一覧: `ollama list`。
4. アプリは自動で最良モデルを使い、初回以降はモデルが常駐して速くなります。
